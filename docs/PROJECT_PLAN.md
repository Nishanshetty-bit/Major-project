# Final-year completion plan (3-week focused MVP)

## Week 1 — Data + ranking
1. Download the Kaggle NSE 2015–2024 dataset.
2. Run `build_market_dataset.py`.
3. Verify 10–20 important stocks and charts.
4. Train FinancialPhraseBank sentiment model.
5. Connect ranking + stock detail + news sentiment.

## Week 2 — Personalization
1. Finish authentication/profile.
2. Finish budget-aware portfolio generation.
3. Persist simulation responses.
4. Calculate behavioral fingerprint.
5. Connect intervention engine to Buy/Sell actions.

## Week 3 — Integration + finalization
1. Dashboard integration.
2. Validation and edge-case testing.
3. UI polish and error states.
4. Deployment.
5. Capture screenshots, prepare report, architecture, results and demo script.

## Must-have vs optional

### Must-have
- Real Kaggle historical data
- Risk metrics
- Explainable ranking
- Sentiment model
- Budget-aware allocation
- Behavioral simulation + profile
- Intervention warning
- Authentication
- MongoDB persistence

### Optional only if time remains
- LSTM/Transformer price forecasting
- Advanced portfolio optimization
- Broker integration
- Push notifications
- Admin analytics

Do not add these optional features before the must-have flow is stable.
